## Claraverse development conventions

- This is the canonical local checkout. Preserve its existing Git history and remote. Use feature branches and descriptive commits; do not create replacement projects.
- Keep the preview on localhost:3000 pointed at this directory. Do not deploy or push to a hosting-connected remote unless requested.
- Lead with ecommerce intelligence, architecture, operations and integrations; storefront development is one part of the operation.
- The globe starts enormous, then contracts smoothly to the centre. Scroll must never reset its orientation. One persistent world rotation combines automatic spin and pointer input, with bounded pitch and no competing camera orbit.
- Keep the Shopify mark behind the globe as a background graphic. Do not put logos, order cards or floating labels on its surface.
- Use continuous illustrative US, European and Indian order traffic with domestic and cross-market routes. Never imply the simulation is actual client traffic.
- Verify with npm run typecheck, npm run lint:site and npm run build. The imported UI library has existing full-lint findings documented in CONTRIBUTING.md.

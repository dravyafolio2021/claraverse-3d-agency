## Cora build contract (a build that breaks these is refused or fails)
1. `package.json` `"build"` script is exactly `"next build"` — Cora runs `next build` itself and ignores any other build script (no prebuild steps, no shell scripts).
2. Packages install with `--ignore-scripts`: use no dependency that needs a postinstall step (e.g. Prisma generate, puppeteer, node-gyp builds, husky). Plain React / Tailwind / UI libraries are fine.
3. No server access from code or config: never use `child_process`, `execSync`, `spawnSync`, read `wp-config`, `/home/…`, `/etc/…`, `/proc/…` or env secrets you were not given. Build-time data comes only from the Cora SDK.
4. One Next.js app at the repository root (or one clear app folder). `package-lock.json` committed. Node.js 20+. Nothing outside the repo.
5. Output is static files only (`out/`): no server code is published. Images: `next/image` with `unoptimized` (Cora sets it).
6. Up to 12 builds an hour per workspace — batch commits, push when the local build passes.
- Cora adds `output: 'export'`, `images.unoptimized` and `trailingSlash` on top of your `next.config` — keep your config simple and compatible with static export.
- Nothing runs on a server at request time: **no API routes, route handlers, middleware, server actions, `cookies()`, `headers()`, ISR or `force-dynamic`**. Cora sets `app/api` and `middleware` aside when building.
- Data is read **at build time**. Cora rebuilds on every push and, for the live site, automatically a few minutes after content changes in the workspace.
- Every dynamic route (`[slug]`) needs `generateStaticParams()` returning at least one entry (use `atLeastOne(...)` from `lib/cora.ts`).
- The build must pass with Node.js 20+ and `npm ci` — commit `package-lock.json`. Never commit `.env*` files with keys.

- Server components by default; `"use client"` only for interactive parts. No large client libraries for simple effects.
- `next/font` with one family; images with explicit sizes; keep pages light — they are served as plain files.

- After pushing, the build log is in Cora (Canvas › the theme › GitHub & AI agent setup › Go live).
